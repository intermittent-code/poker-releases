# 德州扑克好友局 — APK 下载

本仓库**只用于分发 Android 安装包（APK）**，不含源码。

纯虚拟筹码娱乐，**不涉及任何真实货币/现金结算**。

## 下载

请到右侧 **Releases** 页面下载最新版本：

- `app-arm64-v8a-release.apk` — 绝大多数现代手机（推荐）
- `app-armeabi-v7a-release.apk` — 较老的 32 位机型

安装：下载后传到手机，点开安装；首次需允许「安装未知应用」。

## 联机

一台电脑运行服务器 `dart run server/bin/server.dart`；手机 App 选「联机对战」，
填服务器电脑的局域网 IP，房主建房间拿到 6 位房间码发给好友即可同台。
